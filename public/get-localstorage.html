📖 How to Use

🎯 Workflow:

  1. Edit your design using Visual Editor on the main site
  2. Open this page: localhost:3000/get-localstorage.html
  3. Click "Extract Data" to load all localStorage data
  4. Click "Generate CSS" to create fallback CSS code
  5. Copy the CSS and paste it into src/app/globals.css
  6. Test in all browsers - design will be consistent!

🔧 Features:

  • Multi-language Support: Automatically detects TR, EN, ZH localStorage
  • CSS Generation: Creates language-specific fallback CSS with !important
  • Cross-browser: Ensures same design in Chrome, Safari, Firefox, Edge
  • Statistics: Shows element count per language
  • One-click Copy: Easy clipboard integration

💡 Tips:

  • Keep this page bookmarked for quick access
  • Use after every major design change
  • The generated CSS goes in the @layer utilities section of globals.css
  • Visual Editor will still override these styles when active
